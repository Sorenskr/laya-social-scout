# 交友软广抓视频 & 案例拆解工作台

给运营团队用的全网页操作工具，不用懂代码、不用敲黑框命令，所有操作全部在浏览器点按钮完成。

---

## 一、怎么在自己的电脑上打开并开抓？

1. 直接双击文件夹里的 **`一键启动工作台.bat`**（或者 `start.bat`）。
2. 弹出一个黑色窗口（**别关掉它**，关掉就停止后台了），2 秒后浏览器会自动打开页面：`http://localhost:3080`。
3. 抓完想关掉时，直接关掉那个黑色窗口就行。

---

## 二、怎么用 GitHub.com，做到“无论哪台电脑都能看，换台电脑也能直接抓”？

### 1. 让任何电脑打开就能看（看大封面、看数据、看拆解案例）
1. 在 GitHub.com 上建一个仓库，点开仓库里的 **Settings → Pages**，把分支选成 `main` 并保存。
2. 回到本工作台的 **「⚙️ 同步与连接设置」**，把你的 GitHub 仓库地址粘贴进去并点保存。
3. 以后你在自己电脑抓完新视频或拆完新案例，点一下网页右上角绿色的 **「☁️ 一键同步到 GitHub 网页」**，就会自动把最新结果、大封面和拆解案例推上去（你的飞书密码、AI 钥匙和代理账号会自动过滤掉，绝不会传到网上）。
4. 之后你在家里、公司电脑、或者同事的电脑，只要打开你的 GitHub 网页网址，就能直接看到全部视频大封面和案例，还能直接筛选。

### 2. 换到其他电脑也能直接跑抓取
只要把这整个文件夹拷过去，或者在 GitHub 仓库页面点绿色按钮 `Code → Download ZIP` 下载解压到新电脑，双击 **`一键启动工作台.bat`**（新电脑没装过 Node 的话按屏幕提示装一下就行），一模一样可以直接抓、可以拆案例、可以推回 GitHub 汇总。

## 三、防封静默抓、0 额外 AI 费用、飞书每天自动更新怎么用？

1. **用指纹浏览器 / 0元防封独立窗悄悄抓（防封号）**：
   - **方法 A（你电脑装了比特浏览器 / AdsPower）**：先打开比特浏览器软件（无需关闭），回到本工作台首页的「🛡️ 防封静默浏览器通道」卡片里点 **「🔄 重新检测环境」→ 选中你的账号环境 → 点「🪟 打开选中的指纹环境」**，确认里面已登录 IG / FB / X / Threads 即可。
   - **方法 B（不想装第三方或想 0 元省事）**：直接点首页绿色的 **「🛡️ 0元启动专用防封窗口（Edge/Chrome）」**，系统会单独弹出一个隔离缓存的防封窗口（登录状态与你日常浏览器完全隔离）。你在里面登录一次社媒账号就行，之后抓取时会自动像真人一样慢速翻页截封面、每日自动限额（默认 30 次搜词/天），万一遇到验证码会立刻停下发红框提醒你人工过一下，绝不硬闯导致封号。
2. **AI 过滤 & 拆解案例：默认 0 额外费用**：
   - 系统默认开启 **「🆓 本地 0 费用智能引擎（完全免费，不花一分钱）」**，自动根据画面肤色占比/横屏游戏特征 + 多语言黑名单词拦截真人露脸、游戏推广和硬广，并直接套用高转化脚本公式生成植入指南，**不会收取任何额外 AI 费用**（只有你主动展开填了自己的付费 Key 才会走外部接口）。
3. **飞书文档按每天日期实时自动更新**：
   - 去 **「⚙️ 同步与连接设置 → 4. 飞书绑定」**，**方式一**：直接粘贴你现有的飞书电子表格 / 多维表格链接并扫码授权；**方式二（免建应用）**：直接把飞书群机器人 / 多维表格自动化 Webhook 链接贴进去保存。
   - 勾选 **「每天自动按当天日期建子工作表（例如 2026-11-14）」**，抓取过程里每留下一条合格视频，1 秒内直接写进当天日期的表格里，同时网页上也能实时看着封面一张张跳出来。

## 四、平时怎么在网页上操作？（全大白话说明）

1. **选日期抓视频，界面实时看进度**：
   - 点左边 **「⚡ 选日期抓新视频」**，可以选「只抓今天 / 最近3天 / 最近7天 / 自己选起止日期」，点开始抓以后，页面上方会直接出现进度条和实时汉字播报。
2. **每条都带大封面，不用点开就知道内容**：
   - 点左边 **「🎬 抓到的好视频」**，每张卡片左边都有高清大图封面，点一下封面还能直接放大看清细节；系统自动把真人露脸、打游戏画面、直白硬广踢进废片回收站。
3. **看到好视频，丢链接或传截图就能拆案例**：
   - 点左边 **「🔍 丢链接/传图拆案例」**，把外网链接贴进去，或者直接把微信/手机截图拖进来（按 `Ctrl+V` 直接粘贴也行），点「开始帮我拆解」，几秒钟就能给你写出：为什么火、有没有踩雷、以及 3 套能直接照抄的植入脚本。
4. **高清抓封面插件 & 现成热词包**：
   - 在 **「⚙️ 同步与连接设置」** 里，点一下 **「⚡ 一键从 GitHub 自动安装高清抓封面插件」**，就能自动配好开源 `yt-dlp` 工具帮各种外网链接扒真封面。
   - 在 **「📝 搜索词管理」** 里，点 **「🎁 一键导入现成热词包 / 从GitHub拉词」**，不用自己一个字一个字想搜索词。

## 五、扩展到云端容器 / 新平台

- 根目录自带 `vercel.json` 与 `Dockerfile`，需要放云服务器长期跑时可直接部署。
- 新增 TikTok / 抖音 / 小红书等平台，只需在 `lib/collectors/` 复制一份采集文件并在 `lib/collectors/registry.js` 注册即可，不影响现有界面和飞书同步。
